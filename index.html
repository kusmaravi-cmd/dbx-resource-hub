    Move off a legacy data warehouseTeradata, Oracle, SQL Server, Netezza, Synapse or another warehouse is being retired and the SQL estate has to land on Databricks SQL.

    How it usually goes

    1. Assess. Profile workloads and score code complexity so the backlog is sized from evidence, not guesses.
    2. Convert. Transpile SQL and procedural code with rule based and AI assisted converters, then review the exceptions by hand.
    3. Reconcile. Load data, compare source and target row by row, and keep the evidence for sign off.
    4. Cut over in waves. Group by business domain and dependency, run both sides in parallel, then retire the source.
    5. Tune. Right-size serverless SQL warehouses and rebuild the heavy reports on materialized views.

    What a good proposal contains

    • Inventory with complexity scores
    • Target architecture on Unity Catalog
    • Wave plan and effort model
    • Reconciliation approach and exit criteria
