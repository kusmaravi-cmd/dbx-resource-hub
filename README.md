## DataPulse App

[`datapulse-app/`](datapulse-app/) is a platform-agnostic data & AI readiness assessment with enforced levers. It deploys as a Databricks App (Databricks on AWS) and stores data in Unity Catalog. See its [README](datapulse-app/README.md).
